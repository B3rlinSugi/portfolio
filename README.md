# 🚀 Berlin Sugiyanto — Personal Portfolio

A personal portfolio website built to showcase my projects, skills, and experience as a Junior Backend Developer.

🌐 **Live Site:** [berlinsugi.vercel.app](https://berlinsugi.vercel.app)

---

## 🛠️ Tech Stack

- **Framework:** React + Vite
- **Styling:** CSS3 (inline styles)
- **Deployment:** Vercel
- **Languages:** JavaScript, HTML5, CSS3

---

## ✨ Features

- Responsive design for all screen sizes
- Smooth scroll animations with Intersection Observer
- Project showcase with detail modal
- Skills section with accordion layout
- Certifications timeline
- Organization experience section
- Multi-language support (EN/ID)
- Contact section with direct links

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/B3rlinSugi/portfolio.git

# Navigate to project folder
cd portfolio/portfolio

# Install dependencies
npm install

# Run development server
npm run dev
```
